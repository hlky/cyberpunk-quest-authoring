# Lab 1 — One-shot quest

This directory contains the two WolvenKit checkpoints for
[Lab 1](../../book/src/start-here/lab-01.md):

- `start`: an empty project checkpoint before quest resources are added;
- `completed`: the mod-owned questphase, journal, localization, and ArchiveXL
  registration for `cqa001`.

The completed project is structurally validated with WolvenKit 8.19.0. Runtime
proof is still pending and the book does not label this arrangement
runtime-proven.

No extracted vanilla resource is included.
