# Example projects

This directory is reserved for small, reproducible WolvenKit projects that
accompany the book.

Each example should:

- teach one primary concept;
- include a short README naming the matching book chapter;
- contain only redistributable, mod-owned source;
- omit packed archives, extracted vanilla resources, and generated build
  output; and
- use stable resource paths that do not depend on Ghostline.

Implemented examples:

- [`lab-01-one-shot`](lab-01-one-shot/README.md): start and completed
  checkpoints for the `cqa001` one-shot quest.
- [`lab-02-signal-race`](lab-02-signal-race/README.md): start and completed
  checkpoints for the `cqa002` immediate/waiting gate and monitor lab.
- [`lab-03-boundary-check`](lab-03-boundary-check/README.md): start and
  completed checkpoints for the `cqa003` streaming, marker, and nested-trigger
  world objective.
- [`lab-04-handoff-point`](lab-04-handoff-point/README.md): start and completed
  checkpoints for the `cqa004` registered-root, archive-resolved child-phase
  handoff.
- [`lab-05-first-contact`](lab-05-first-contact/README.md): start and completed
  checkpoints for the `cqa005` community-backed contact, one-line scene,
  named outcome, and delayed cleanup lifecycle.

Runtime status and evidence-promotion boundaries are recorded in the book's
[evidence and version matrix](../book/src/reference/evidence-version-matrix.md).
