# Example projects

This directory is reserved for small, reproducible WolvenKit projects that
accompany the book.

Each example should:

- teach one primary concept;
- include a short README naming the matching book chapter;
- contain only redistributable, mod-owned source;
- omit packed archives, extracted vanilla resources, and generated build
  output; and
- use stable resource paths that do not depend on Ghostline.

Implemented examples:

- [`lab-01-one-shot`](lab-01-one-shot/README.md): start and completed
  checkpoints for the `cqa001` one-shot quest.

The longer release sequence remains in [`../HANDOFF.md`](../HANDOFF.md).
