# Scenes

Scenes provide dialogue, choices, timed events, animations, and named outcomes.

This section will progress through:

- scene anatomy;
- actors, performers, props, and debug symbols;
- screenplay stores and graph nodes;
- sections, dialogue events, and timing;
- one spoken line and one exit;
- player choices and embedded localization;
- scene-local quest nodes and conditions;
- entry points, named exits, and questphase sockets;
- animation and lipsync resources;
- interruption, return, and cleanup structures;
- scene, event, localization, screenplay, actor, performer, and handle ID
  domains.

Exact graphs will be rendered as deterministic SVG rather than WolvenKit graph
screenshots.
