# Gameplay patterns

This section will become a cookbook of native quest patterns built on the
foundations taught earlier.

Planned families include:

- text-message offers, conversations, and holocalls;
- reaching, leaving, and meeting;
- device interaction, hacking, and terminal documents;
- time gates, items, shards, clues, and rewards;
- combat, encounter waves, optional stealth, and planting;
- rescue, escort, defend, carry, trunk placement, and workspots;
- doors and destructible targets;
- vehicle mounting, riding, driving, stealing, delivery, cleanup, chase, and
  racing;
- two-way choice gates, n-way switches, and outcome-dependent debriefs.

Each pattern will state which world, journal, scene, community, device, or
character assets it expects. A graph pattern will not pretend to synthesize
those assets automatically.
